## Brain v1

- Explicit `disabled`, `learn`, and `frozen_eval` settings under `NEXUS_BRAIN_*`;
  disabled reproduction opens no store and performs no retrieval or write.
- One private namespace, `aegisops.investigator`; every query includes agent and
  namespace predicates. No shared memory, Engram promotion, or cross-agent access.
- The writer accepts only an exact `AgentObservableRun` allowlist built field-by-field in
  runtime. It cannot receive scenarios, scores, correctness, plans, recovery, or harness
  state. Self-diagnoses are always `self_reported/unverified`.
- Strict schema-version-1 episodic and unverified candidate-procedure records carry
  stable IDs, validity intervals, private provenance, lifecycle/dispute state,
  supersession, retention policy, and version.
- SQLite persistence with typed canonical JSON, transactional writes, deduplication,
  explicit Windows-safe connection closure, integrity checks, and atomic snapshots.
- Deterministic lexical retrieval uses only the generic prompt and pinned run start,
  filters inactive/old/future records, and enforces one-query, record-count, character,
  token, and two-second bounds outside the agent loop.
- Retrieved context is canonical escaped JSON inside a delimited untrusted historical-data
  boundary. It cannot add tools, permissions, policy, identity, instructions, evidence,
  timeout, turns, or diagnostic-call budget.
- Secret-shaped values, harness markers, invalid namespaces, unknown fields, malformed
  rows, and identity/policy memory types are rejected. Brain failures and timeouts become
  explicit `brain_failure`; no silent memoryless fallback exists.
- Each run records mode, schema/writer/retriever/renderer identity, bounds, status,
  latency, as-of, ranked IDs/content hashes, context hash/size, Brain-attributable input,
  truncation, writes/latency, memory counts, and pre/post snapshot hashes.
- Frozen evaluation is hash-verified and read-only. Every run verifies equal pre/post
  hashes and zero writes. Benchmark schema 3 remains backward compatible.
- `targeted` performs one named evaluator-controlled investigation. Brain smoke and
  baseline commands require frozen read-only storage to prevent within-session learning.

## Experimental Design

The byte-hashed protocol in `docs/experiments/brain-v1-protocol.json` pre-registers the
authorized calibration and a deferred leave-one-scenario-out study. The generic prompt
makes pre-run Brain v1 a reusable procedural prefix, not incident-specific recall. The
targeted learn run and five-scenario frozen smoke are mechanism/security calibration;
they cannot support a causal improvement claim. Brain calibration cannot be locked as
an official baseline. Current protocol SHA-256:

## Known Limitations

- Lexical retrieval can be empty for the intentionally generic benchmark prompt; v1
  fails closed instead of injecting unrelated history.
- Procedural extraction is deterministic and conservative; it is never evaluator-
  validated truth. Directly contradictory self-reports are disputed and not retrieved.
- SQLite supports this one-agent local experiment; PostgreSQL/Engram migration is deferred.
- No semantic, reflective, shared, vector, or graph memory exists in Brain v1.
- Five scenarios are insufficient for independent learning-effect estimates.
